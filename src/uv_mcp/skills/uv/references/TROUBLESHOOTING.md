# UV Troubleshooting & Resources

## Troubleshooting

- **ENOENT**: Add `$HOME/.local/bin` to PATH
- **Package not found**: Check PyPI name, use absolute path with `--from`
- **Version conflicts**: `uv python pin 3.14`
